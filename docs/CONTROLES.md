# Controles - Mundo Expandido

Objetivo: GTA San Andreas clásico para PC, SA 1.0 US.

## Menú principal
- **F5:** abrir o cerrar el menú principal.
- **1:** recuperar salud.
- **2:** restaurar chaleco.
- **3:** eliminar el nivel de búsqueda policial.
- **4:** recibir $5,000.
- **ESC:** cerrar los paneles.

## Panel de administrador
- **F6:** abrir o cerrar el panel de administrador.
- **1:** añadir $10,000.
- **2:** añadir $100,000.
- **3:** restaurar salud y chaleco.
- **4:** eliminar el nivel de búsqueda policial.
- **5:** añadir $1,000,000.
- **ESC:** cerrar los paneles.

Las teclas numéricas ejecutan acciones únicamente cuando el panel correspondiente está abierto. El menú principal y el panel de administrador se excluyen entre sí.

## Estado
Estas funciones están incluidas en el script CLEO compilado. La compilación automática pasó; falta validar las acciones dentro de una instalación real de GTA SA 1.0 US.
