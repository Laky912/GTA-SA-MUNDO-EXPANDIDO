# Controles

## Panel principal
- **F5**: abrir/cerrar el panel principal.
- **ESC**: cerrar los paneles abiertos.

## Panel de administrador
- **F6**: abrir/cerrar el panel de administrador.
- **1**: añadir $10,000.
- **2**: añadir $100,000.
- **3**: restaurar salud y chaleco.
- **4**: eliminar el nivel de búsqueda policial.
- **5**: añadir $1,000,000.
- **ESC**: cerrar los paneles.

El panel de administrador está pensado para el modo libre de un jugador y para pruebas. Sus acciones alteran la partida actual; se recomienda guardar antes de usar funciones de administración. No está conectado a una cuenta, servidor ni sistema multijugador.

## Estado
Los controles están implementados en la fuente CLEO. La compilación automatizada y las pruebas dentro del juego son pasos obligatorios antes de declarar el panel listo para instalar.
