# GTA San Andreas — Mundo Expandido

Proyecto de modificación original para **GTA San Andreas clásico (PC, versión 1.0 US)**.

## Objetivo

Convertir el modo libre en una experiencia ampliada, en español y ligera para equipos modestos. El proyecto se desarrollará como un paquete único; no se publicarán módulos sueltos como si fueran versiones finales.

## Características previstas

- Dos protagonistas originales adultos, intercambiables.
- Actividades y trabajos: taxi, policía, transporte, reparto y carreras.
- Economía, encargos, propiedades y negocios.
- Vehículos modernos de creación propia o con permisos compatibles.
- Zonas nuevas integradas con el mapa original.
- Sistema opcional de relaciones románticas no explícitas.
- Interfaz y textos en español.

## Compatibilidad y rendimiento

- Objetivo: GTA San Andreas clásico para PC, ejecutable 1.0 US.
- Instalación existente del usuario: CLEO, Mod Loader y SilentPatch.
- Equipo objetivo: 4 GB de RAM.
- Prioridad: estabilidad, scripts ligeros y recursos de baja resolución.
- No se requieren ENB ni paquetes de texturas HD.

## Estado real

**Desarrollo en curso.** El repositorio contiene especificación, configuración y fuentes de desarrollo. Todavía no contiene un mod compilado y probado; no debe instalarse como si fuera una versión jugable.

## Instalación

La distribución final será un único ZIP con la estructura de instalación, instrucciones en español y notas de versión. Se publicará cuando la compilación y las pruebas estén completas.

## Aviso

Este es un proyecto de fans no oficial. Grand Theft Auto y sus elementos originales pertenecen a sus respectivos titulares. No se incluyen archivos del juego ni recursos extraídos de otros títulos.
